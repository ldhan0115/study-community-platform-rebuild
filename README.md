# Study Community Platform

Java와 Spring Boot 기반의 스터디 모집 및 커뮤니티 플랫폼입니다.

## 프로젝트 목표

스터디 개설, 참가 신청, 승인 및 거절 기능을 구현하고
인증·인가, 비즈니스 상태 관리, 트랜잭션과 동시성 제어를
학습하고 적용하는 것을 목표로 합니다.

## 기술 스택

- Java 21
- Spring Boot 4.1.2
- Spring MVC
- Spring Security
- Gradle
- JUnit 5
- MySQL
- Spring Data JPA 
- Docker 
- GitHub Actions

## 주요 기능

- 회원 관리
- 스터디 관리
- 참가 신청 및 승인
- 댓글 관리

## 실행 방법

Windows:

    gradlew.bat bootRun

## 테스트

Windows:

    gradlew.bat clean test
